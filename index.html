ELETRICIDADE BÁSICA

O que é um Circuito Elétrico? (Loop Fechado)

Para a corrente elétrica fluir e realizar trabalho, ela precisa sair da fonte positiva (5V ou Pino HIGH), atravessar o componente de proteção/carga e retornar ao polo negativo (GND / 0V) formando um caminho fechado.

💡 Regra prática: Sem retorno ao GND, o circuito está aberto e nada liga. Ligar 5V direto no GND sem carga causa curto-circuito!

ENTRADA / SAÍDA DIGITAL

Pinos Digitais 2 a 13

Operam com apenas dois estados lógicos binários: HIGH (Ligado / 5V) ou LOW (Desligado / 0V).

  • Configuração: pinMode(pino, OUTPUT) ou pinMode(pino, INPUT_PULLUP)
  • Escrita/Leitura: digitalWrite(pino, HIGH/LOW) e digitalRead(pino)
  • Corrente máxima segura por pino: ~20 mA (sempre use resistor com LEDs!).
CATÁLOGO DE BANCADA

Componentes do Kit & Identificação Visual de Resistores

ESTRUTURA

Protoboard (Matriz de Contatos)

  • Barramentos Laterais (+ Vermelho e - Azul): Conduzem energia ao longo de toda a extensão lateral para distribuir 5V e GND.
  • Linhas Centrais (1 a 30): Conectadas internamente em grupos de 5 furos (A-B-C-D-E e F-G-H-I-J), isoladas pelo vão central.
SAÍDA LUMINOSA

LED + Resistor de 220 Ω

  • Polaridade do LED: Perna Longa = Anodo (+) vai ao pino de sinal; Perna Curta / Lado Chanfrado = Catodo (-) vai ao GND.
  • Lei de Ohm Aplicada: (5V - 2V) / 220 Ω ≈ 14 mA (protege o LED e o pino do Arduino).
  • Cores (220 Ω): Vermelho – Vermelho – Marrom.
ENTRADA DIGITAL

Push Button + Resistor 10 kΩ

  • Encaixe: Posicione o botão "cavalgando" o vão central da protoboard para não dar curto permanente entre os terminais.
  • Cores (10 kΩ): Marrom – Preto – Laranja (ou use INPUT_PULLUP interno via código!).
ENTRADA ANALÓGICA

Potenciômetro Linear 10 kΩ

  • Ligação Padrão: Ponta 1 no 5V, Pino Central no A0 (varia de 0V a 5V → 0 a 1023), Ponta 3 no GND.
  • 💡 Dica de Bancada: "Se funcionar ao contrário (aumentar para a esquerda), basta inverter os fios 5V e GND nas pontas!"
POTÊNCIA & ATUAÇÃO

Motor DC + Transistor NPN (2N2222 / BC337) + Resistor 1 kΩ + Diodo (1N4007 / 1N4148)

🚫 Por que não ligar o Motor DC direto no pino do Arduino?

Um pino digital do Arduino fornece com segurança cerca de 20 mA (máximo absoluto 40 mA). Um micro motor DC exige de 100 mA a 350 mA para partir. Ligá-lo direto queima a saída do microcontrolador. O Transistor NPN atua como uma chave/amplificador eletrônico controlado pela Base via resistor de 1 kΩ (Marrom - Preto - Vermelho).

🛡️ Qual a função do Diodo em paralelo (Diodo de Roda Livre / Flyback)?

A bobina interna do motor acumula energia magnética. Quando o PWM desliga o motor rapidamente, essa bobina gera um pico de tensão reversa de alta voltagem que pode destruir o transistor e resetar o Arduino. O diodo ligado em paralelo (com a faixa prateada apontando para o 5V / +) dissipa essa corrente reversa com segurança.

🚨

Painel de Alertas Críticos de Segurança na Bancada

Leia obrigatoriamente antes de energizar sua placa Arduino UNO via cabo USB.

⚠️ Alerta 1: Cabo USB Desconectado ao Montar

Desconecte sempre o cabo USB antes de inserir, remover ou alterar jumpers e componentes na protoboard. Mexer nos fios com a placa energizada é a maior causa de curtos acidentais entre 5V e GND.

🛑 Alerta 2: Cuidado com o Resistor do Botão (Pull-down)

Nunca use resistor de 220 Ω no lugar do 10 kΩ no circuito pull-down do botão, nem ligue 5V direto no GND ao pressionar a chave. Isso drena corrente excessiva, provoca aquecimento, queda de tensão e reinicialização imediata da placa Arduino.

🛑 Alerta 3: Proibido Motor DC Direto no Pino Digital/PWM

Jamais conecte os fios do Motor DC diretamente nos pinos 2 a 13. Utilize obrigatoriamente o circuito de acionamento com Transistor NPN + Resistor de 1 kΩ na Base + Diodo de proteção em paralelo com o motor.

Roteiro das Aulas & Simulador Interativo PWM

1. Estrutura Básica de todo Código Arduino

Todo programa (sketch) em C++ para Arduino é dividido em duas funções principais obrigatórias:

void setup() {
  // Roda UMA ÚNICA VEZ quando o Arduino liga ou reseta.
  // Usado para configurar os pinos:
  pinMode(13, OUTPUT);       // Define pino como SAÍDA
  pinMode(2, INPUT_PULLUP);  // Define pino como ENTRADA
}

void loop() {
  // Roda INFINITAMENTE em ciclo contínuo após o setup().
  // Aqui vai a lógica principal (ler botão, acender LED):
  digitalWrite(13, HIGH);    // Liga (5V)
  delay(500);                // Espera 500 milissegundos
  digitalWrite(13, LOW);     // Desliga (0V)
  delay(500);
}

2. Passo a Passo de Envio na Arduino IDE

Após validar no Tinkercad e montar na protoboard física, siga esta sequência para gravar o código:

  1. 1. Conecte o Cabo USB: Plugue o cabo USB Tipo A/B entre o computador e o Arduino UNO (o LED ON da placa deve acender).
  2. 2. Selecione a Placa: No menu superior da Arduino IDE, acesse Ferramentas > Placa > Arduino AVR Boards > Arduino Uno.
  3. 3. Selecione a Porta COM: Vá em Ferramentas > Porta e escolha a porta que exibe COMx (Arduino Uno).
  4. 4. Verificar e Carregar (Upload): Clique no botão ➔ Carregar (Seta para a direita). Os LEDs RX/TX piscarão rapidamente até aparecer "Carregamento concluído".
Resumo Aula 1: Sinais digitais possuem apenas 2 estados: HIGH (5V) ou LOW (0V). Com eles criamos pisca-piscas, semáforos (Ficha 1) e lemos botões interruptores (Ficha 2).

1. Entrada Analógica: De 0V–5V para 0–1023

O mundo real não é apenas ligado/desligado. Para ler a posição de um potenciômetro no pino A0, o Arduino usa um conversor Analógico-Digital (ADC de 10 bits):

  • Comando: int v = analogRead(A0);
  • Escala de Leitura: 0V → 0 | 2.5V → 512 | 5.0V → 1023 (1024 níveis).

2. Saída PWM (~): Simulando Tensão Variável (0–255)

O Arduino UNO não possui saída analógica pura, mas os pinos com til (~3, ~5, ~6, ~9, ~10, ~11) ligam e desligam centenas de vezes por segundo (PWM - Modulação por Largura de Pulso):

  • Comando: analogWrite(pinoPWM, brilho);
  • Escala de Escrita (8 bits): 0 (0% Duty Cycle = 0V) até 255 (100% Duty Cycle = 5V).

3. A Ponte Mágica: Função map()

Como a entrada analógica lê de 0 a 1023 e a saída PWM aceita apenas de 0 a 255, usamos a função matemática map() para converter proporcionalmente as escalas:

int leitura = analogRead(A0);             // Lê de 0 a 1023
int pwm = map(leitura, 0, 1023, 0, 255);  // Converte p/ 0 a 255
analogWrite(9, pwm);                      // Controla brilho/motor
Resumo Aula 2: Combinando analogRead(A0) + map() + analogWrite(), construímos o Dimmer de LED (Ficha 3) e o Controle de Velocidade de Motor DC com Transistor (Ficha 4).

🔧 Guia de Troubleshooting ("Se não funcionar...")

1. O LED não acende de jeito nenhum:

Verifique se as pernas do LED não estão invertidas (inverta Anodo e Catodo) ou se as duas pernas foram espetadas na mesma linha numerada da protoboard (em curto).

2. O LED acende muito fraco:

Confira as cores do resistor! Se você usou o de 10 kΩ (Marrom-Preto-Laranja) em vez do de 220 Ω (Vermelho-Vermelho-Marrom), a corrente cai para 0.3 mA. Veja também se não esqueceu pinMode(A0, OUTPUT);.

3. Funciona no 5V mas não no pino A0:

Confirme se o código foi realmente carregado (Upload concluído na IDE) e se o jumper está no furo exato do A0.

ATIVIDADE 2 • NÍVEL BÁSICO

Interruptor Digital (Push Button + LED)

Controle um LED através da leitura digital de um botão. Compare a abordagem moderna com resistor interno (INPUT_PULLUP) e a abordagem clássica com resistor pull-down externo de 10 kΩ.

📦 Checklist de Materiais

⚖️ Nota Comparativa: INPUT_PULLUP vs Pull-Down Externo (10 kΩ)
• Com INPUT_PULLUP (Ficha 2 - Pino 2 e LED no 8): Ativa o resistor interno do próprio Arduino conectado ao 5V. O botão vai ligado entre o Pino 2 e o GND. A lógica fica invertida: solto lê HIGH; pressionado lê LOW.
• Com Pull-Down Externo (Manual de Bancada - Pino 2 e LED no 13): Usa um resistor físico de 10 kΩ entre o Pino 2 e o GND, e o botão liga o 5V ao Pino 2. Pressionado lê HIGH.

// ==========================================
// ATIVIDADE 2: Interruptor Digital (Botão + LED)
// Abordagem Principal: INPUT_PULLUP (Lógica == LOW)
// ==========================================

const int pinoBotao = 2;
const int pinoLED   = 8;

void setup() {
  pinMode(pinoBotao, INPUT_PULLUP); // Ativa resistor pull-up interno
  pinMode(pinoLED, OUTPUT);
}

void loop() {
  int estado = digitalRead(pinoBotao);

  // Com INPUT_PULLUP, botão pressionado conecta ao GND (LOW)
  if (estado == LOW) {
    digitalWrite(pinoLED, HIGH); // Acende o LED

    digitalWrite(pinoLED, LOW);  // Apaga o LED

🔧 Guia de Troubleshooting ("Se não funcionar...")

1. O LED já começa aceso sem apertar o botão:

O botão tactile tem 4 pernas (duas a duas já são conectadas internamente). Gire o botão em 90 graus ou use os dois terminais do mesmo lado do vão central.

2. O LED pisca sozinho ao aproximar a mão dos fios:

O pino 2 está "flutuando" (sem referência). Certifique-se de que usou INPUT_PULLUP no código ou de que o resistor de 10 kΩ está firme no GND.

3. O Arduino apaga os LEDs e desconecta do USB ao apertar:

Curto-circuito! Você ligou 5V direto no GND através do botão. Desconecte o USB imediatamente e revise a tabela de ligações.

ATIVIDADE 3 • NÍVEL MÉDIO

Dimmer de LED com Potenciômetro e Saída PWM

Leia uma tensão contínua variável na porta analógica A0 (0 a 1023), converta a escala com map() e controle suavemente a intensidade luminosa do LED no pino ~9.

📦 Checklist de Materiais

📌 Atenção ao Pino com Til (~9): A função analogWrite() só produz controle de brilho real nos pinos PWM marcados com ~ na placa (3, 5, 6, 9, 10 e 11). Se ligar no pino 8 ou 13, o LED apenas ligará ou desligará bruscamente!

Ponto A (Origem) Ponto B (Destino) Componente / Observação
Potenciômetro Pino 1 (Esq) Barramento 5V (+) Alimentação positiva do divisor
Potenciômetro Pino Meio Arduino Pino A0 Sinal analógico variável (0V a 5V)
Potenciômetro Pino 3 (Dir) Barramento GND (-) Referência 0V do potenciômetro

🛠️ Passo a Passo de Execução

  1. Posicione o Potenciômetro: Encaixe os 3 terminais do potenciômetro em 3 linhas diferentes da protoboard.
  2. Conecte as Pontas e o Meio: Ligue uma extremidade ao 5V, a outra extremidade ao GND e o pino central exatamente na entrada A0.
  3. Conecte o LED no Pino PWM ~9: Ligue o pino ~9 ao resistor de 220 Ω, ao Anodo do LED e feche no GND.
  4. Teste o Giro: Ao girar o eixo, o brilho deve subir gradualmente de 0% a 100%. Se diminuir ao girar para a direita, inverta os jumpers 5V e GND nas pontas do potenciômetro.
🚀 Desafio Extra (Monitor Serial em Tempo Real)

Ative a comunicação serial com Serial.begin(9600); no setup() e imprima no Monitor Serial da Arduino IDE tanto o valor bruto lido (0 a 1023) quanto o valor PWM convertido (0 a 255) para inspecionar os números na tela do computador!

💻 Código C++ (Ficha 3: Dimmer PWM + Monitor Serial) 
// ==========================================
// ATIVIDADE 3: Dimmer de LED com Potenciômetro e PWM
// ==========================================

const int pinoPot = A0;
const int pinoLED = 9; // Pino PWM (~9)

void setup() {
  pinMode(pinoLED, OUTPUT);
  Serial.begin(9600); // Desafio Extra: Inicia Monitor Serial
}

void loop() {
  // 1. Lê o valor analógico do potenciômetro (0 a 1023)
  int v = analogRead(pinoPot);

  // 2. Converte proporcionalmente da escala 0-1023 para 0-255
  int brilho = map(v, 0, 1023, 0, 255);

  // 3. Aplica o sinal PWM no LED
  analogWrite(pinoLED, brilho);

  // Desafio Extra: Exibe leituras no Monitor Serial
  Serial.print("Leitura A0: ");
  Serial.print(v);
  Serial.print(" | PWM (0-255): ");
  Serial.println(brilho);

  delay(20); // Pequena pausa para estabilidade
}

🔧 Guia de Troubleshooting ("Se não funcionar...")

1. O brilho não varia (fica sempre aceso ou sempre apagado):

Verifique se o fio que vai para a porta A0 está realmente no pino central do potenciômetro e não em uma das pontas.

2. O potenciômetro esquenta ao girar até o fim:

Desligue o USB imediatamente! Você inverteu o pino do meio com o 5V/GND, criando um curto direto entre 5V e GND quando a resistência zera.

3. O brilho aumenta quando giro para a esquerda (anti-horário):

Comportamento normal dependendo do lado montado. Basta trocar entre si os fios 5V e GND conectados nos dois pinos das extremidades do potenciômetro.

  3. Proteja a Base com 1 kΩ: Ligue o pino ~10 ao pino central (Base) do transistor usando o resistor de 1 kΩ (Marrom-Preto-Vermelho).
  4. Aterre o Emissor: Ligue o Emissor ao barramento GND.
  5. Instale o Diodo e o Motor: Conecte o Diodo em paralelo entre o Coletor e o 5V, garantindo que a faixa prateada esteja do lado do 5V (+). Conecte os dois fios do Motor DC nesses mesmos dois pontos (Coletor e 5V).
🚀 Desafio Extra (Limiar de Partida: v > 512)

Motores DC não conseguem vencer a inércia com PWM muito baixo (apenas "apitam"). Modifique o código para que o LED continue variando de 0 a 255 normalmente, mas o Motor DC só seja acionado quando a leitura v > 512 (metade do curso do potenciômetro); abaixo disso, envie analogWrite(10, 0)!

💻 Código C++ (Ficha 4: LED + Motor DC + Desafio v > 512) 
// ==========================================
// ATIVIDADE 4: Controle Conjunto de LED e Motor DC
// ==========================================

const int pinoPot   = A0;
const int pinoLED   = 9;  // PWM do LED (~9)
const int pinoMotor = 10; // PWM da Base do Transistor (~10)

void setup() {
  pinMode(pinoLED, OUTPUT);
  pinMode(pinoMotor, OUTPUT);
}

void loop() {
  // Lê o potenciômetro (0 a 1023) e mapeia para PWM (0 a 255)
  int v   = analogRead(pinoPot);
  int pwm = map(v, 0, 1023, 0, 255);

  // Atualiza o brilho do LED continuamente
  analogWrite(pinoLED, pwm);

  // Aciona o Motor DC proporcionalmente
  analogWrite(pinoMotor, pwm);

  /* --- DESAFIO EXTRA: Acionar motor apenas quando v > 512 ---
  if (v > 512) {
    analogWrite(pinoMotor, pwm);
  } else {
    analogWrite(pinoMotor, 0);
  }
  ------------------------------------------------------------- */

  delay(20);
}

🔧 Guia de Troubleshooting ("Se não funcionar...")

1. O LED varia o brilho, mas o motor não gira:

Verifique a ordem dos pinos do seu Transistor NPN (2N2222 vs BC337 podem ter Coletor e Emissor invertidos dependendo do fabricante) e confira se o Emissor está no GND comum.

2. O transistor esquenta muito e o motor não gira:

O Diodo está invertido! Se a faixa prateada do diodo estiver virada para o Coletor em vez do 5V (+), a corrente passa toda por dentro do diodo em curto, desviando do motor.

3. O motor faz um zumbido agudo em baixa rotação mas não roda:

Normal em PWM abaixo de ~30%: a tensão média ainda não vence o atrito estático do eixo. Continue girando o potenciômetro ou aplique o código do Desafio Extra (v > 512).
